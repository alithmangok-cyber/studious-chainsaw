On-point Scholarship
it is a free-access,non-profit informational website designed to help refugee students easily find and understasnd available schorlaship opportunities.
The platform centralizes key scholarship details such as eligibility requirements ,application status ,deadlines and official links,making  access to information simpler and more transparent.

PROJECT PURPOSE
Many refugee students miss opportunities due to:
1.Scattered information
2.Unclear eligibility
3.Lack of untimely updates
This project aims to bridge the gaps by providing a single , easy-to-navigate with verified scholarship information

FEATURES
List of scholarships 
Detailed applications sections
Links to websites and forms 
Easy navigation using ancor links 
Mobile friendly layout
Semantic HTML for accessibility
